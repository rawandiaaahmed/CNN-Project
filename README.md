Handwritten Digit Recognition using CNN

Project Overview

This project focuses on building a Convolutional Neural Network (CNN) model to recognize and classify handwritten digits from 0 to 9 using the MNIST dataset.

The model learns visual patterns and features from grayscale images to accurately predict handwritten digits.

Dataset

* MNIST Handwritten Digits Dataset.
* 70,000 grayscale images.
* 60,000 training images.
* 10,000 testing images.
* Image size: 28 × 28 pixels.
* 10 classes (digits 0–9).

Project Workflow

* Loading and exploring the MNIST dataset.
* Data preprocessing and normalization.
* Reshaping images for CNN input.
* Building CNN architecture using Conv2D and MaxPooling2D.
* Applying Flatten and Dense layers.
* Using Dropout to reduce overfitting.
* Compiling and training the model.
* Evaluating model performance.
* Visualizing training and validation accuracy and loss.
* Testing predictions on unseen images.
